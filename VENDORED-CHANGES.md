# Upstream Source Integration

Upstream: tidesdb/tidesdb-java v0.8.3 (commit: 4ce8f8a520022242d1d785bf594df5be0772a35b)

## Upstream source changes

None.

`./build.sh` clones and builds the pinned upstream Java and JNI source without copying, formatting, or patching it. The native build compiles the upstream JNI bridge against the install-shaped header tree generated by TidesDB itself.

## Unified-project source

`src/main/java/com/tidesdb/NativeLibrary.java` is maintained by this project and replaces the same class while assembling the unified artifact. It preserves the upstream package, API, copyright, and MPL-2.0 header while providing this artifact's deterministic embedded-library extraction behavior.

All other `com.tidesdb` classes in the final JAR come from the unchanged pinned `tidesdb-java` artifact built under `build/work/`.
